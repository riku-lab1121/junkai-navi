# 巡回ナビ Ver.7.2 UI統一・小改善版

## 入っている機能
- MAP（OpenStreetMap / Leaflet）
- 自販機登録
- 14日ごとの定期巡回判定
- 7日程度の中間補充判定
- 定期巡回 = 清掃 + 原料 + 集金
- 追加作業 = 水汲み / 排水 / 集金 / 原料
- 今日の巡回の自動作成
- 作業開始 / 終了タイマー
- 休憩開始 / 終了タイマー
- 休憩合計 / 残り時間
- 巡回・作業履歴をブラウザ内 localStorage に保存
- PWA用 manifest / service worker

## 起動
ローカルでは、フォルダ内で簡易HTTPサーバーを起動してください。

python3 -m http.server 8080

その後ブラウザで:
http://localhost:8080

iPhoneに配布する場合はHTTPSでホスティングすると「ホーム画面に追加」しやすくなります。

## 注意
- 現在のルート順は道路ルートではなく、登録位置どうしの直線距離を使った簡易並び替えです。
- 地図タイルはオンライン接続が必要です。
- 会社の正式データを入れる前の個人用プロトタイプ想定です。

- 機種名 / 標準作業時間 / メモを登録・編集・削除
- 自販機登録・編集で機種を選択
- 機種を選ぶと標準作業時間を初期反映
- 自販機データに modelId / modelName を保存


## Ver.7.2
- 設置場所を最優先表示へ統一
- 機種名 / 管理No / エリアはサブ表示
- 自販機一覧 / MAP詳細 / 手動巡回 / おすすめ巡回 / トラブル受付で表示ルール統一
- 自販機登録で設置場所を必須化
- 機種選択時、表示名が空なら機種名を自動入力
- 確定ボタンの保存中表示と二重タップ防止を強化
- 既存データはそのまま維持

## Ver.7.2.1 hotfix
- 機種追加の「保存する」が反応しない不具合を修正
- 機種マスターのイベント登録を設定タブ依存から切り離し
- 同じイベントが重複登録される問題を防止
- 保存中表示・二重タップ防止・ストレージ同期を追加

## Ver.7.3 使いやすさ優先版
- 機種追加・編集をモーダルから独立画面へ変更
- 保存後は設定 > 機種へ自動で戻る
- 機種画面では下部固定ボタンとモーダルの重なりを廃止
- 大きな入力操作は独立画面にする方針へ変更
- 既存データ形式は維持

## Ver.7.3.1 表示ルール整理
- 表示名 = 施設・会社など大まかな場所（最も大きく太字）
- 設置場所 = 階数・部屋・ロビーなど詳細位置
- 機種 = 自販機の種類（小さく表示）
- 一覧・MAP・巡回など共通の表示関数を修正

## Ver.7.3.2 拠点名と機種を完全分離
- 「表示名」を「拠点名」に変更
- 拠点名 = 建物・施設・会社など、その自販機がある大まかな場所
- 設置場所 = 3F、自販機コーナー、1Fロビー等
- 機種 = 100RS、APEX等。主表示には使わず補助情報として小さく表示
- 機種マスターへ機種を追加しても、拠点名には自動追加しない
- 一覧では拠点名をより大きく太字化

## Ver.7.3.3 表記変更
- 「拠点名」を「設置先施設」に変更
- 設置先施設を一覧のメイン情報として大きく太字表示
- 設置場所・機種・管理Noは補助情報として表示
- 機種マスターと設置先施設は引き続き完全に別管理
