# 巡回ナビ Ver.7.2 UI統一・小改善版

## 入っている機能
- MAP（OpenStreetMap / Leaflet）
- 自販機登録
- 14日ごとの定期巡回判定
- 7日程度の中間補充判定
- 定期巡回 = 清掃 + 原料 + 集金
- 追加作業 = 水汲み / 排水 / 集金 / 原料
- 今日の巡回の自動作成
- 作業開始 / 終了タイマー
- 休憩開始 / 終了タイマー
- 休憩合計 / 残り時間
- 巡回・作業履歴をブラウザ内 localStorage に保存
- PWA用 manifest / service worker

## 起動
ローカルでは、フォルダ内で簡易HTTPサーバーを起動してください。

python3 -m http.server 8080

その後ブラウザで:
http://localhost:8080

iPhoneに配布する場合はHTTPSでホスティングすると「ホーム画面に追加」しやすくなります。

## 注意
- 現在のルート順は道路ルートではなく、登録位置どうしの直線距離を使った簡易並び替えです。
- 地図タイルはオンライン接続が必要です。
- 会社の正式データを入れる前の個人用プロトタイプ想定です。

- 1週間の巡回詳細で、その日の巡回全体を「1日前/1日後」「指定日数」「曜日指定」で同じ週の中へ移動できます。

- 1週間の巡回詳細から、その日の巡回予定をまとめて削除できます。周期設定・前回作業日・実績は削除しません。

## Ver.11.18.1 1週間巡回の個別移動

- 選択した自販機だけをその日の巡回から外せる

- 移動先に同じ自販機がある場合は重複させず、確認して処理
- 周期設定・前回作業日・実績は変更しない
- 従来の順番変更・作業内容変更は各行から引き続き利用可能

## Ver.11.18.2 巡回漏れチェック・おすすめ順改善

## Ver.11.18.3 月間行動計画の期限優先修正

- 同一エリアの台数が多くても期限から大幅に前倒ししない

## Ver.11.18.4 巡回順・週間重複修正
- 今日のおすすめ作成から作業時間上限を削除
- 月間自動作成から1日の作業時間上限を削除
- 今日の巡回は「同一エリアを回り切る → 近い施設順 → 同じ施設は全台連続」に変更
- 作成済み巡回を「今の巡回をエリア・距離順に並べ直す」で再最適化可能
- 1週間の巡回に「重複チェック」を追加
- 同じ自販機が複数日にある場合、早い日だけ残して後の日をまとめて削除可能
- 週間移動時、移動先に同じ自販機があっても元の日からは必ず外すよう修正

## Ver.11.18.5 週1巡回の月間計画反映修正
- 月間計画の基本巡回を「最終基本巡回日 + 現在の基本巡回周期」から再計算
- 週1へ変更後も古い14日周期の nextRegular が残っていて月間計画から抜ける問題を修正
- 基本巡回周期を編集した時、古い次回予定日がそのままなら新周期に合わせて自動更新
- ユーザーが次回予定日を手入力で変更している場合は手入力を優先
- 月間自動作成後に週1基本巡回の予定回数を自動監査
- 月間行動計画の自動作成欄に「週1基本巡回 ○/○回」を表示
- 週1反映漏れが残った場合は該当自販機名を警告表示

## Ver.11.18.6 曜日・日数指定の週1ルール
- 曜日指定が1曜日だけの作業は週1回として扱う
- 曜日指定が2曜日以上なら選択曜日ごとに巡回可能
- 日数指定が7日以上は週1回以下として扱う
- 日数指定が2〜6日は週内複数回を許可
- 原料・排水の日数指定が0〜1日/空欄の場合は誤設定として7日（週1）へ補正
- 月間計画生成時、週1扱いの同一作業が同じ週に2回入らないよう重複防止

## Ver.11.18.7 手動編集と自動作成の安全統合
- 月間行動計画で手動編集・日付移動した自動予定を「手動調整済み」として保護
- 自動作成をやり直しても、保護された予定は削除・上書きしない
- 手動予定に含まれる自販機/作業/元期限を自動作成候補から除外し、二重登録を防止
- 手動予定の台数を1日の最大台数計算にも含め、その周囲へ残りを自動配置
- 1週間の巡回で移動した自販機も手動調整として記録
- 1週間から外した自販機は抑制記録を残し、自動再計算で即復活しにくくした
- 月間表の状態に「手動調整」を表示
- 自動作成欄に「手動調整 ○件保護」を表示

## Ver.11.18.9 次回巡回日の即時同期

- 明示変更した次回日を月間・週間・今日の巡回再計算で最優先
- おすすめ/自動作成の未完了巡回は自販機設定変更時に一旦外して新設定から再判定
- 手動作成・手動移動・完了済みの巡回は保護して勝手に消さない
- 今日のおすすめ巡回は再同期後にエリア・距離順も再計算
- 基本巡回周期だけ変更した場合は「最終巡回日 + 新周期」に自動更新し、古い次回日を残さない

## Ver.11.19.0 今日・1週間・月間の統合同期
- 今日/週間の巡回（routes）と月間行動計画（tasks）の相互同期層を追加
- 週間で自販機を別日に移動すると、月間側も同じ日へ移動
- 週間から自販機を外すと、月間側からも同じ予定を外す
- 月間で日付を移動すると、週間/今日側の巡回も同じ日へ移動
- 月間自動作成後、1週間/今日の巡回予定へ同じ内容を自動反映
- 今日のおすすめ/手動巡回を作った場合も、その日の月間計画へ反映
- 手動調整・完了済みは保護し、自動同期で勝手に上書きしない
- 巡回画面に「同期チェック」を追加し、既存データのズレを一括修復可能
- 同一週の同じ自販機の重複予定も同期チェック時に整理


## Ver.11.19.2 次回予定日の警告連動

- 基本巡回予定が入っている場合は、通常の集金もその予定で行う前提として「集金○日経過」の赤警告も残さない
- 未来の次回予定日は「次回まで○日」または「本日巡回予定」と表示
- 設定した次回予定日を過ぎた場合は「予定○日超過」として再び赤警告
- 既存の登録自販機・巡回周期・手動調整・今日/週間/月間の同期データは維持

## Ver.11.19.3 今日の巡回→月間の完全同期
- 今日の巡回を手動作成した場合、その日の月間巡回自販機を今日の巡回と完全一致させる
- 月間側に残った古い自動予定の自販機を整理し、19台なら月間も19台へ揃える
- 巡回以外の月間予定や、自販機を持たない手書きメモ予定は保持
- 今日の巡回へ1台追加した場合も月間へ即時反映
- 今日の作業内容変更も月間側へ即時反映
- 同期チェック時は「今日○台 = 月間○台」と結果を表示
- 月間表の今日行は、今日の巡回が存在する場合はその台数を即時表示
